# Everyday Things, Two Lines

Two lines explaining a queue to a 10-year-old, written by `main.ts` to
`/output/entry.txt`, for the make.fun competition
[Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

## Run

```sh
node main.ts
```

This writes exactly two lines of at most 400 characters to `/output/entry.txt`.
